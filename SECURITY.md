# Security Policy

agy-rc gives whoever holds the token (or reaches the port when no token is set) the
ability to run commands on the host as the user running the server. Keep it inside your
tailnet and always set `AGY_TOKEN`.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/fjguillen-96/agy-rc/security/advisories/new)
rather than opening a public issue. You should get a response within a few days.
